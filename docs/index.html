Install

Install the package from a checkout and add Chromium.

terminal
pip install -e .
python -m playwright install chromium

Start your Expo web build with npx expo start --web, then pass its host and port.

Quick start

One command discovers screens and captures every target.

terminal
store-shots --host 127.0.0.1 --port 19006 \
  --platform playstore --screens 6

The CLI prints screens, then writes a manifest and validation report. --dry-run previews them.

CLI reference

Flags that change most runs.

FlagDefaultPurpose
--platformallRepeat for playstore, appstore, amazon.
--deviceallFilter to one device class, such as phone.
--screensprofileCapture exactly this many screens per variant.
--max-routes25Limit how many screens discovery returns.
--max-actions24Buttons inspected per screen.
--routeautoUse explicit routes and skip discovery.
--checkoffCompare saved images with required sizes.

Python API

The facade keeps the same arguments as the CLI.

capture.py
from store_shots import ExpoShotter

summary = ExpoShotter(
    host="127.0.0.1",
    port=19006,
    platforms=["playstore"],
    screens=6,
).run()
print(summary["captures"])

Settings validates configuration once. Discovery, settling, capture and orchestration are separate services with replaceable protocols.

Screen discovery

Links are crawled. Controls are clicked and replayed before capture.

Links

Internal anchors are crawled. External URLs and assets are ignored.

Buttons

Buttons, tabs, ARIA roles and pointer-cursor divs are clicked. Destructive actions are skipped.

Flows

Pass a JSON flow file for onboarding that needs typing.

Verify the output

Check the saved files before you upload them.

terminal
store-shots --check --output-dir ./store-assets
store-shots --list-platforms

--check compares each image with its required size and exits non-zero on a mismatch. Manifests sit beside the images.
